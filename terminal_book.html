Search & Find

7

Example: grep -rn "TODO" src/
💡 Combine: grep -rinl for recursive + case-insensitive + filenames only.
find . -name

Globbing & Expansion

10
*
Match any characters (zero or more)
Example: ls *.js
💡 Globs are not regex.
?
Match exactly one character
Example: ls file?.txt
[abc] / [a-z]
Match one of set / range
Example: ls file[1-3].txt
[!abc]
Match any character NOT in set
** BASH
Recursive subdirs (globstar)
Example: ls **/*.go
💡 zsh: on by default. bash: needs shopt -s globstar.
*.{js,ts}
Brace expansion: multiple patterns
Example: ls *.{js,ts}
file{1..5}.txt
Brace expansion: range
Example: touch file{1..5}.txt
{01..10}
Zero-padded brace expansion
mv f.txt{,.bak}
Shorthand: expand to mv f.txt f.txt.bak
mkdir -p src/{lib,bin,test}
Create multiple dirs at once

Redirection & Pipes

9
cmd > file
Redirect stdout (overwrite)
Example: ls > filelist.txt
💡 This will overwrite the file without asking.
cmd >> file
Redirect stdout (append)
Example: date >> log.txt
cmd 2> file
Redirect stderr to file
cmd &> file / 2>&1
Both stdout+stderr to file
cmd | tee file
Stdout AND write to file
Example: ls | tee output.txt
cmd1 | cmd2
Pipe stdout to stdin of next cmd
Example: ls | grep '.txt'
cmd1 | xargs cmd2
Stdin lines become args for cmd2
Example: find . -name '*.log' | xargs rm
$(cmd)
Command substitution: inline output
Example: echo "Today is $(date)"
< (cmd)
Process substitution: treat output as file
Example: diff <(ls a) <(ls b)
💡 Creates a temp file descriptor. Incredibly useful.

Useful Combos

11
cmd1 && cmd2
Run cmd2 only if cmd1 succeeds
Example: mkdir newdir && cd newdir
cmd1 || cmd2
Run cmd2 only if cmd1 fails
Example: test -f file || echo 'not found'
cmd &
Run command in background
Example: node server.js &
sort | uniq -c | sort -rn
Count unique lines, sorted by frequency
Example: cat access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head
ls -lhS
List files sorted by size (largest first)
tail -f log.txt | grep --line-buffered ERROR
Live-filter log for errors
find . -name '*.tmp' -mtime +7 -delete
Delete .tmp files older than 7 days
cat file.txt | xargs -I{} echo "Item: {}"
Process each line with a command
watch -n 2 cmd LINUX
Re-run command every 2 seconds
Example: watch -n 2 df -h
💡 macOS: brew install watch
du -sh */ | sort -rh | head
Top 5 largest folders
ls *.bak 2>/dev/null || echo 'No backup files'
Try command, fallback on failure
